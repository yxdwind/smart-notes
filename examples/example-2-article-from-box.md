# 案例 2：从卡片盒长出一篇公众号文章

> 场景标签：写作 · 选题 · 卡片盒风暴
> 涉及章节：ch09（分享你的洞见）、ch08（发展想法）、ch04（没有人完全从零开始写作）

## 场景

你是自媒体作者，下周要交一篇公众号文章，脑子一片空白。常规做法是开选题会、刷热点、硬憋——按卡片笔记法，正确做法是：看卡片盒里哪些主题已经形成了笔记集群，让文章从积累里"长出来"。

## 你怎么说

> 我要写一篇公众号文章，别让我凭空想选题。先看我的卡片盒（附笔记导出或指向我的笔记库），找出已经形成集群的 2-3 个主题；选一个最有话说又适合公众号传播的，按卡片笔记法的成文流程帮我搭出文章结构，并列出每段可以引用哪些现成笔记。

## AI 执行路径

1. 读 `chapters/ch09-step5-share-insights.md`（卡片盒风暴、先决定不写什么）和 `chapters/ch08-step4-develop-ideas.md`（集群与链接）
2. 扫描笔记库，按"同一主题下笔记数量+链接密度"识别集群，而不是按最近灵感
3. 选定集群后，把相关永久笔记按论证顺序排成线性初稿——此时论证缺口才会暴露
4. 对缺口给出补笔记任务，而不是直接编内容

## 方法论如何落地

- **卡片盒风暴取代头脑风暴**：头脑风暴靠易得性偏向（最近、生动、押韵的先冒出来）；卡片盒风暴看到的是"被反复证明有趣的素材"
- **先决定不写什么**：初稿可视化后第一步是删——把与论点无关的笔记移入"剩余部分"，抑制把全部素材用上的冲动
- **多稿并行**：这篇用不上的集群留给下一篇，卡住就切换项目

## 关键输出片段（模拟）

```markdown
选题：为什么"记不住"不是你的错——认知科学视角的笔记方法
（集群：笔记方法论 · 已有 14 条永久笔记 · 链接密度最高）

结构（由笔记序列生成，非凭空设计）：
1. 开头钩子 → 引用笔记[闪念 0912：为什么收藏夹吃灰]
2. 问题定位 → 引用[永久：重复阅读制造已懂错觉]
3. 原理 → 引用[永久：存储强度/提取强度负相关]
4. 方法 → 引用[永久：文献笔记三标准] + [永久：每日6条]
5. 结尾 → 回收开头钩子

⚠️ 论证缺口：第 3-4 节之间缺一个"为什么有效"的实验证据
→ 补笔记任务：检索间隔重复/测试效应的经典实验，写成文献笔记
```

## 书中依据

- "选题不看灵感，看卡片盒里哪些集群已自然形成"（ch09）
- "头脑风暴是预测什么值得写，卡片盒是看到什么值得写"（ch09）
- "第一步是决定某部分不写什么"（ch09）
- 排成线性初稿时论证缺口才会暴露（ch09，步骤四关联）
