# 案例 1：把一本书读成卡片盒

> 场景标签：阅读 · 读书笔记 · 文献笔记 → 永久笔记
> 涉及章节：ch04（三类笔记）、ch06（阅读和理解）、ch07（记卡片盒笔记）、ch08（发展想法）

## 场景

你刚读完申克·阿伦斯的《卡片笔记写作法》 itself（或任何一本书），书里划了几十处、有零散想法，但这些内容散落在各处，既没沉淀也没法复用。目标是：把这本书"吃进"自己的卡片盒，变成以后写作时随时可调用的素材。

## 你怎么说

> 帮我用卡片笔记写作法把《卡片笔记写作法》这本书的读书笔记整理进我的卡片盒。我的原始材料：微信读书划线导出（附后）。请按"文献笔记 → 永久笔记 → 建立链接"的完整流程处理，输出每条永久笔记的成品和入库位置建议。

## AI 执行路径

1. 加载 SKILL.md 总纲，识别这是「输入→处理→入库」全流程任务
2. 读 `chapters/ch06-step2-read-understand.md`（文献笔记怎么写）和 `chapters/ch07-step3-take-notes.md`（永久笔记标准与四步入库）
3. 按"用自己的话转述"原则处理你的划线——每条划线先判断：值得转述（进文献笔记）/ 只是提醒（丢弃）/ 已懂（跳过）
4. 文献笔记合并同类项后升级为永久笔记，每条完成入库四步

## 方法论如何落地

- **转述而非摘抄**：划线"笔记的质量取决于这个网格"不会被原样保存，而是转述为"单条笔记的价值不由它本身决定，由它连接的网络决定"——先懂才能记
- **一个想法一条笔记**：一章内容会被拆成 3-6 条独立可读的永久笔记，而不是一篇大而全的章节摘要
- **自问三连**：写每条永久笔记前先问——这对我正在思考的什么问题有意义？谁讨论过它？它与盒中哪些笔记矛盾或互补？

## 关键输出片段（模拟）

```markdown
### 永久笔记 20260918-a｜笔记网络决定单条笔记的价值

单条笔记的价值不由其本身决定，而由它嵌入的引用与反向引用网络决定
（Luhmann, 1992）。因此记笔记时的核心动作不是"保存"，而是"寻找
这条笔记与已有笔记的关系"——没有关系可建的想法，要么还没想清楚，
要么不属于这个卡片盒。

来源：《卡片笔记写作法》第八章"发展想法"
关联：[[20260918-b 弱连接带来意外思路]]（矛盾：强连接保深度，弱连接供意外）
索引：[[主题-笔记方法论]]
```

## 书中依据

- 文献笔记标准："简短、精选、用自己的语言"（ch06）
- 永久笔记标准："像为别人写作一样"，脱离原文语境仍自足（ch07）
- 入库规则：挂到相关笔记后 → 编号 → 互链 → 索引可达（ch07）
- 新旧笔记对质："发现重复、同一概念的关键差异、矛盾与对立"（ch08）
