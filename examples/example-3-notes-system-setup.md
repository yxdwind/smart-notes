# 案例 3：从零设计自己的笔记系统

> 场景标签：知识管理 · 工具选型 · 流程落地
> 涉及章节：ch03（工具箱四件套、卢曼卡片盒结构）、ch04（三类笔记分立）、ch07（入库规则）、ch10（习惯化）

## 场景

你收藏了很多文章、装过 Notion/Obsidian/印象笔记，但每次都是"收藏式笔记"——存进去就再也没打开。想认真搭一套能长期用的系统，不知道工具怎么选、流程怎么定。

## 你怎么说

> 我想按卡片笔记写作法搭一套自己的笔记系统，主要在手机和电脑上用，平时读公众号、论文和书。帮我做两件事：① 给出工具选型建议（说清理由）；② 给出一套从"读到一篇文章"到"永久笔记入库"的可执行流程，要具体到每天花多少时间。

## AI 执行路径

1. 读 `chapters/ch03-writing-overview.md`（工具箱四件套：多了没用少了不行）和 `chapters/ch04-four-principles.md`（三类笔记分立标准）
2. 按"你的输入源 + 双端需求"匹配工具，而非推荐功能最全的
3. 读 `chapters/ch07-step3-take-notes.md`（四步入库）和 `chapters/ch10-step6-habits-afterword.md`（低门槛习惯化），把流程压到你真能坚持的强度
4. 给出第一周的最小启动方案，而不是完美系统蓝图

## 方法论如何落地

- **工具四件套**：书写工具（手机速记/微信服务号）+ 文献管理（Zotero）+ 卡片盒（Obsidian，支持反向链接）+ 编辑器——多了没用，少了不行
- **三类笔记各就各位**：公众号收藏 → 闪念笔记；论文要点 → 文献笔记；每日升级 → 永久笔记
- **低门槛入口**：按 ch10 原则，入口必须低到"阅读时顺手就拿笔"——所以手机端入口是必选项而非可选项

## 关键输出片段（模拟）

```markdown
工具选型（按你的输入源定制）：
- 手机闪念：flomo 微信服务号（点开即写，零启动成本）
- 文献管理：Zotero（论文+网页剪藏，浏览器插件一键存）
- 卡片盒：Obsidian（双向链接+本地存储，Dataview 做索引）
- 写作：任何编辑器（成稿阶段工具不重要）

每日流程（合计 15-20 分钟）：
1. 阅读/碎片时间：随手记闪念（不整理，只捕捉）     0 分钟额外
2. 晚上 10 分钟：过一遍今天的闪念——
   值得保留的 → 转成文献笔记（自己的话+出处）
   有想法的   → 升级为永久笔记（自足可读，1-3 条即可）
3. 入库四步：挂相关笔记后 → 编号 → 双链 → 索引

第一周目标：只练"晚上 10 分钟"这一个动作，别管结构。
```

## 书中依据

- 工具箱："书写工具、文献管理工具、卡片盒、编辑工具。多了没用，少了不行。"（ch03）
- 分类判据："晚上合上项目文件夹后桌上只剩笔和纸，就是分清楚的标志。"（ch04）
- 习惯化："不与旧习惯决裂……从最小动作切入"（ch10）
- 反面警告："先找完美工具再开始"就是拖延（ch11）
